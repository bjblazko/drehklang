VU-Meter für das Vollbild

Zwei Entwürfe in Gerätegröße (360 px, rund), angetrieben von einem simulierten Musiksignal. Kein Ton, nur Pegel.

Signal

So würde es auf dem Gerät gebaut

  • Alles Statische (Skala, Lampenlicht, Glas, unbeleuchtete Segmente) ist ein fertiges Bild, ca. 253 KB im PSRAM. Die Vorschau malt es ebenfalls nur einmal.
  • Pro Frame kommen nur Zeiger bzw. leuchtende Segmente dazu. Auf dem Gerät wird nur dieser Bereich neu übertragen.
  • Annahme: 0 VU = −14 dBFS. Die Digitalanzeige zeigt dBFS-Spitzen, 0 ist die Übersteuerungsgrenze. Die rote PEAK-Lampe am Zeigerinstrument leuchtet ab −1 dBFS.
