# VU Meter Visualization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A full-screen visualization view, opened from Now Playing's options panel, with an analog VU meter and an FL bar meter that look exactly like the approved preview, plus a keep-awake toggle.

**Architecture:** The audio task measures per-channel RMS and peak in `AudioOutputStage::noteStereo32()` and publishes them lock-free. Pure, host-tested models turn them into a needle position (VU ballistics), a peak lamp and bar/hold segments. The static art is pre-rendered from the preview's own drawing code into RGB565 C arrays. LVGL shows it, with the needle drawn live as a polygon and the lit segments shown as clipped regions of a "fully lit" image.

**Tech Stack:** C++17, LVGL 8.4.0, Arduino-ESP32 3.x (pioarduino), Unity via `pio test -e native`, Node + `@napi-rs/canvas` for the art generator.

**Spec:** `docs/superpowers/specs/2026-11-03-vu-meter-design.md`. The visual reference is `docs/superpowers/specs/2026-11-03-vu-meter-preview.html`. Read both before any task.

## Global Constraints

- The look is the preview, "genau so": palette, lamps, glass, fonts, scale layout, needle tempo, segment behaviour.
- 0 VU = −14 dBFS. Full scale of the needle = +3 VU (`10^(3/20)` × 0 VU).
- VU ballistics: ω = 20 rad/s, ζ = 0.8, 1 ms substeps, stops at 0 (bounce −0.15 × v) and 1.06 (bounce −0.2 × v).
- PEAK lamp: lit while either channel's sample peak exceeds −1 dBFS, then fades linearly over 350 ms.
- Bar meter: 32 segments; scale points (dBFS → position) `(-50,0) (-30,.25) (-20,.42) (-10,.64) (-6,.75) (-3,.85) (0,1)`; red from −3 dB; instant attack, release 0.55 positions/s, peak hold 1.5 s, then hold falls 0.4 positions/s (never below the level).
- No brand names or logos anywhere, not in the art and not in the UI copy.
- UI copy is English, like the rest of the app. The options button is labelled **"Visuals"** (my call; the spec's "Visualisierung" was the working name).
- **Never print, lock or allocate on the audio task** (AGENTS.md). Nothing may print while `UsbMscStorage::exporting()`.
- No `bit`, `min`, `max`, `abs`, `round`, `degrees`, `radians` as member names (Arduino.h macros).
- On this toolchain `uint32_t` is `unsigned long`: give `std::min<uint32_t>` etc. explicitly.
- File-local constants in `ScreenManager*.cpp` must not share a name with a `ScreenManager` class constant.
- `ScreenManagerMenu.cpp`'s `kMenuEntries` and every stored enum are append-only.
- Every font generated with `lv_font_conv` keeps `--no-compress`, uses `@latest` and keeps `--lv-font-name`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Mono files**: ESP32-audioI2S hands mono as identical L/R. Both bars must match and the needle must read the same as for a stereo file at that level. Tested in Task 1.
2. **Low sample rates (8–22.05 kHz audiobooks)**: decoder blocks arrive up to ~150 ms apart. The meter must not flicker to zero between blocks, so the stale hold is 250 ms. Tested in Task 1.
3. **Hot masters and EQ headroom gain > 1**: RMS or peak above full scale must pin the needle at its stop and fill the bar, never index past segment 31. Tested in Tasks 2 and 3.
4. **A long stall** (display off and on, a blocking rescan): a huge `dtMs` must leave the needle finite and inside [0, 1.06], with no jump through the stop. Tested in Task 2.
5. **Keep-awake while paused**: the toggle on must not hold the display awake when playback is paused or stopped. Tested in Task 4.

**Interfaces:**
- Produces, in `namespace drehklang::signal` (`StereoLevels.h`, header-only, no Arduino):
  - `struct StereoLevels { float rms[2] = {0, 0}; float peak[2] = {0, 0}; bool fresh = false; };` Linear, 1.0 = full scale.
  - `class StereoLevelMeter`. Single producer (audio task) and single consumer (main loop), lock-free, using `std::atomic<uint32_t>` holding float bits.
    - `void noteBlock(const int32_t *interleaved, size_t words, float gain)`: sets the latest block's RMS per channel (it replaces, not accumulates) and raises the per-channel peak since the last `take()`. Samples are normalised by 2^31 and multiplied by `gain`. An odd trailing word is ignored.
    - `StereoLevels take()`: returns the latest block RMS and the peaks since the last take, then resets the peaks. `fresh` is true when at least one block arrived since the last take.
  - `class LevelHold { public: StereoLevels apply(const StereoLevels &in, uint32_t dtMs); static constexpr uint32_t kStaleMs = 250; };` A fresh input passes through and is remembered. A stale one returns the remembered levels until `kStaleMs` without a fresh one, then zeros.
- Produces, in `namespace drehklang::playback`:
  - `PlaybackDriver`: `virtual signal::StereoLevels readLevels() { return {}; }`. Not pure, so the four test fakes stay unchanged.
  - `PlaybackStateMachine::readLevels()`: returns `{}` unless the state is `Playing`, otherwise `driver_.readLevels()`.
- `AudioOutputStage` owns a `signal::StereoLevelMeter levels_`. `noteStereo32` calls `levels_.noteBlock(interleaved, words, gain)` once per call. It also gets `signal::StereoLevels takeLevels()`, which returns `{}` when `volumeStep() == 0 || outputGain() == 0` (muted shows nothing, as the spectrum does).
- `Esp32AudioI2SDriver::readLevels()` override → `audioOutputStage().takeLevels()`, without `mutex_` (same reasoning as `readRecentSamples`).

### Task 2: Needle ballistics, scale, peak lamp and needle geometry

**Files:**
- Create: `lib/visualizer/VuNeedle.h`
- Test: `test/test_vu_needle/test_vu_needle.cpp`

**Interfaces:**
- Produces, in `namespace drehklang::visualizer::vu`:
  - `constexpr float kRefDbfs = -14.0f;` `float zeroVuLinear();` (= 10^(−14/20) ≈ 0.19953) `constexpr float kFullScaleVu = 1.4125375f;` (= 10^(3/20))
  - `float needleTarget(float rmsL, float rmsR);` Returns `((rmsL + rmsR) / 2) / zeroVuLinear() / kFullScaleVu`, clamped to [0, 1.2] (the stop does the rest).
  - `class NeedleBallistics { public: void update(float target, uint32_t dtMs); float position() const; float velocity() const; };` Uses the global constants. `dtMs` is clamped to 100 inside.
  - `class PeakLamp { public: void update(float peakL, float peakR, uint32_t dtMs); float brightness() const; /* 0..1 */ };` Threshold `10^(-1/20)` ≈ 0.89125.
  - `struct NeedlePoint { float x, y; };` `std::array<NeedlePoint, 4> needlePolygon(float position);` Pivot (180, 318), tip radius 168, span ±48° from vertical (`angle = -span + 2·span·position`), half-width 1.8 at the pivot and 0.5 at the tip. Point order: pivot−n, tip−n, tip+n, pivot+n, with n = (cos a, sin a).
  - `struct PixelArea { int16_t x1, y1, x2, y2; };` `PixelArea needleArea(float position);` The polygon's bounds, grown by the shadow offset (+3, +5) and a 3 px margin, clamped to 0..359. Inclusive.
