# Circuit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A third game, Circuit: a pseudo-3D time-attack racer with its own full-screen renderer and a three-voice sound chip.

**Architecture:** Pure, host-tested logic (`CircuitGame`, `CircuitRenderer`, `ChipVoices`) in `lib/games` and `lib/playback`; thin device glue (`CircuitPresenter`: render task on core 0, stripe push on core 1, panel ownership in `LvglGlue`); a `ScreenManagerCircuit.cpp` like the other games.

**Tech Stack:** C++17, PlatformIO (`native` for tests with Unity, `esp32-s3` firmware), LVGL 8 (touch only on this screen), Arduino_GFX QSPI, FreeRTOS, ESP-IDF I2S via `ToneOutput`.

**Spec:** `docs/adr/0030-circuit.md`

## Global Constraints

- Game logic and renderer: no LVGL, no Arduino, explicit `nowMs` clock, 8 ms sub-steps, integer fixed point with carried remainders (ADR 0023).
- Throttle is always full once the countdown ends; touching anywhere brakes.
- Steering: the knob sets an angle that stays; **±2 detents around centre are dead zone (straight)** because the knob is imprecise; clamp at ±12.
- Name "Circuit"; all assets self-drawn by `scripts/generate-circuit-sprites.py`.
- Never `Serial.printf` from core 0 (AGENTS.md). No `bit`, `min`, `max`, `abs`, `round`, `degrees`, `radians` as member names (Arduino macros).
- `ScreenKind` is append-only.
- Panel: 360×360 RGB565, native byte order (LV_COLOR_16_SWAP 0).

## Review Focus

- A finger resting on the brake that slides must not fire the leave-swipe, and a finger sliding off the screen must release the brake (`PRESS_LOST`).
- Leaving the screen mid-race (swipe, lock, display off) must stop the render task from pushing and give the panel back to LVGL, and silence all three voices.
- A long loop stall (SD, USB) must not teleport the car through a computer car: dt is capped and sub-stepped (test pins it).
- Knob jitter of ±1–2 detents on a straight must not steer (dead-zone test).
- Records: a fresh device (no NVS key) shows "--:--.-" and the first finished lap becomes the record (test on the record logic).

### Task 1: `playback::ChipVoices` (pure)

**Files:** Create `lib/playback/ChipVoices.h`; Test `test/test_chip_voices/test_chip_voices.cpp`.

**Produces:**
```cpp
struct ChipEffect { uint16_t startHz, endHz, durationMs; int16_t level; bool noise; };
class ChipVoices {
  void setEngine(uint16_t hz, int16_t level);   // live, glides, level 0 = off
  void setNoise(uint16_t clockHz, int16_t level); // held noise, level 0 = off
  void play(const ChipEffect &e);              // one-shot, decays, sweeps
  void silence();
  bool active() const;
  int16_t nextSample(uint32_t sampleRate);     // audio side only
};
```
Tests: engine pitch by zero crossings; frequency change keeps phase (no sample jump > level); effect decays to 0 by its duration; sweep ends near `endHz`; mix of three full-level voices stays within int16; silence() stops at once.

### Task 2: `ToneOutput` plays `ChipVoices`; `CHIP` serial command

**Files:** Modify `lib/drivers-audio/ToneOutput.h/.cpp`, Create `lib/games/ChipPlayer.h`, Modify `src/main.cpp` (command, wiring). Verify with `pio run -e esp32-s3`.

**Produces:** `games::ChipPlayer` interface (`engine(hz, level)`, `noise(clockHz, level)` held, `effect(ChipEffect)`, `silenceChip()`), implemented by `ToneOutput` (claims the DAC at 22050 Hz, sums `tone_` and `chip_`, clamps). Note: deviates from the ADR's "sample source" wording — summing both is simpler and keeps blips intact.

### Task 3: Tracks and `games::CircuitGame` (pure)

**Files:** Create `lib/games/CircuitTrack.h`, `lib/games/CircuitTracks.h`, `lib/games/CircuitGame.h`; Test `test/test_circuit/test_circuit.cpp`.

**Produces:** `CircuitGame` with `Phase {Select, Countdown, Race, Over}`, `EndReason {None, TimeUp, Wrecked}`, `Sound {None, Countdown, Go, Checkpoint, Lap, Bump, Crash, Wrecked}`, `selectTrack(int)`, `startCountdown(nowMs)`, `steer(int detents)`, `setBraking(bool)`, `tick(nowMs)`, `takeSound()`, accessors for snapshot (`z()`, `x()`, `speed()`, `steering()`, `revs()`, `gear()`, `damage()`, `timeLeftMs()`, `lap()`, `lapTimeMs()`, `bestLapMs()`, `offRoad()`, `squealing()`, `cars()`), `CircuitTrack` with `segmentAt(z)`, `kSegmentLength`.
Tests: throttle full after GO and only then; braking slows; dead zone ±2 keeps x on a straight; ±3 drifts; curve without steering pushes outward; off-road caps speed and adds damage; rear-ending a car slows and damages; a scenery hit is a crash; damage 100 → Wrecked; time 0 → TimeUp; checkpoint adds time; a lap completes and records best; 500 ms stall does not pass through a car; deterministic replay.
