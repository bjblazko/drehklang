# Licence texts

The full texts of the licences under which the components in
[THIRD-PARTY.md](../THIRD-PARTY.md) are distributed, one file per SPDX
identifier. They are the SPDX License List's reference texts
(github.com/spdx/license-list-data); `GPL-3.0.txt` is this repository's
own `LICENSE`.

The MIT and BSD texts are templates (`<year> <owner>`): each component's
own copyright line is in THIRD-PARTY.md and on the device under
Settings > Licences (`lib/about/Credits.h`). A firmware release ships this
folder next to the binary.
